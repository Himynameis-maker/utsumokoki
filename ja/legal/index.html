出典・クレジット

MP3への書き出しには、JavaScript製MP3エンコーダ「lamejs」1.2.1（LAME由来、LGPLライセンス）を利用しています。cdnjs（cdnjs.cloudflare.com）から配信されるものを読み込んでいます。

音声の読み込み（デコード）・再生・波形の描画には、ブラウザ標準の Web Audio API と Canvas を使用しています。WAVの書き出しと音量・トリムの処理は、このページ自身のプログラムで行っています。

各ライブラリの名称・商標はそれぞれの権利者に帰属します。

アップロードとプライバシー

読み込んだ音声ファイルは、お使いの端末のブラウザ内だけで処理されます。サーバーへアップロードされることはなく、当サイトが音声データを保存・収集・閲覧することもありません。

変換後のファイルも端末内で生成され、そのまま端末にダウンロードされます。ページを閉じる・再読み込みすると、読み込んだデータは破棄されます。

本ツールは、お使いのブラウザに設定や履歴を保存しません（広告配信に関するCookieを除きます。下記「広告について」をご覧ください）。個人を特定する情報は取得しません。
